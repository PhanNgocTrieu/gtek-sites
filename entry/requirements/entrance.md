Implementation Plan — Details
Phase 1 — Structure (Weeks 1–2)
Tech stack: Next.js (React framework) + Tailwind CSS. This is the industry standard for professional company sites — fast, SEO-friendly, easy to host free on Vercel.
What gets built:

Site shell: responsive navigation bar with the 5 pages (Home, About, Services, Projects, Contact), a sticky header, and a footer with contact info + licenses
Color palette: deep navy/slate for trust and professionalism, with amber/gold accents (earthy, engineering feel)
Home hero section: "Your Partner in Ground Truth and Solutions" tagline with a Get in Touch CTA button
Domain registered on Cloudflare Registrar (~$10/year, cheapest reputable option) — suggested domain: gtekengineering.ca

Phase 2 — Content (Weeks 3–4)
About Us page: Wayne's full bio, credentials (M.Eng., P.Eng., licensed in MB/SK/BC), the 2018 ACEC award, and membership in Canadian Geotechnical Society and Canadian Dam Association. A professional headshot slot should be reserved.
Services page: Four collapsible accordion sections:

Geotechnical Engineering (12 items)
Dam Safety, Instrumentation & Management (9 items)
Project Administration & Construction Support (4 items)
Material Testing (4 items)

Projects page: A filterable grid organized into 9 categories (Resources/Mining, Dam Safety, Infrastructure, Industrial, Commercial, Hydraulic, Water/Wastewater, First Nations, Public/Land). Each card shows the project name and category — Wayne can expand with descriptions later.
Contact page: A simple form (Name, Company, Email, Message + service interest checkbox), the Winnipeg location, and a Google Maps embed.
Phase 3 — Polish (Weeks 5–6)

SEO: Page titles, meta descriptions, geo-targeting for Winnipeg/Manitoba, Google Search Console submission
Mobile: Full responsive testing on phone/tablet — critical since clients may look up the site on site
CMS integration: Connect Sanity CMS so Wayne can edit without touching code (see below)
Analytics: Google Analytics 4 for basic traffic visibility

Editing Without Code (For Non-Technical Users)
Once the site is live, Wayne can use Sanity Studio — a browser-based visual editor. The workflow is:

Log in at studio.gtekengineering.ca (no installs needed)
Edit any text on the site (bio, service descriptions, tagline) using a word-processor-like interface
Add a new project by filling in a simple form: project name, category, description — it appears on the site automatically
Swap images by uploading a new file — no design skills needed

This means Wayne never needs to open code, use a terminal, or contact a developer for routine content changes. The only time a developer is needed is for major redesigns or new features.
